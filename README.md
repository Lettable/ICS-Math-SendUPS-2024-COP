## **Chapter 4: Quadratic Equations (CH4)**

**Question 1:**  
**Solve the quadratic equation:**  
  2x² – 5x + 2 = 0  
*(e.g., see Exercise 4.7 in your text)*

- **Key Formula:**  
  x = (–b ± √(b² – 4ac))/(2a)

- **Solution:**  
  Here, a = 2, b = –5, c = 2.  
  Discriminant D = (–5)² – 4·2·2 = 25 – 16 = 9.  
  Thus, x = (5 ± 3)/4 → x = 8/4 = 2 or x = 2/4 = ½.

---

**Question 2:**  
**Factorize:**  
  x² + 5x + 6  
*(e.g., see Exercise 4.3)*

- **Solution:**  
  x² + 5x + 6 factors as (x + 2)(x + 3),  
  so the roots are x = –2 and x = –3.

## **Chapter 9: Fundamentals of Trigonometry (CH9)**

**Question 3:**  
**Prove that:**  
  sin²θ + cos²θ = 1  
*(e.g., see Definition and Basic Identity section, Ex. 9.1)*

- **Key Definitions:**  
  sin θ = (opposite)/(hypotenuse), cos θ = (adjacent)/(hypotenuse)  
  and the Pythagorean theorem gives (opposite)² + (adjacent)² = (hypotenuse)².

- **Solution:**  
  Let a right triangle have sides a (opposite), b (adjacent), and c (hypotenuse).  
  Then sin θ = a/c and cos θ = b/c.  
  So, sin²θ + cos²θ = (a² + b²)/c² = c²/c² = 1.

## **Chapter 10: Trigonometric Identities (CH10)**

**Question 4:**  
**Prove that:**  
  1 + tan²θ = sec²θ  
*(e.g., see Identity Exercises, Ex. 10.2)*

- **Key Formulas:**  
  tan θ = sin θ/cos θ ⇒ tan²θ = sin²θ/cos²θ  
  sec θ = 1/cos θ

- **Solution:**  
  1 + tan²θ = 1 + sin²θ/cos²θ = (cos²θ + sin²θ)/cos²θ = 1/cos²θ = sec²θ.

## **Chapter 11: Trigonometric Functions and Their Graphs (CH11)**

**Question 5:**  
**Sketch the graph of y = sin x and state its amplitude, period, and phase shift.**  
*(e.g., see Graphical Representation, Ex. 11.1)*

- **Key Form (for a sine function):**  
  y = A sin(Bx – C) + D, where:  
  Amplitude = |A|, Period = 2π/|B|, Phase shift = C/B

- **Solution:**  
  For y = sin x, A = 1, B = 1, C = 0, D = 0.  
  Thus, amplitude = 1, period = 2π, phase shift = 0.  
  Plot key points:  
  x = 0 → 0, x = π/2 → 1, x = π → 0, x = 3π/2 → –1, x = 2π → 0.

## **Chapter 12: Applications of Trigonometry (CH12)**

**Question 6:**  
**Solve a triangle using the Law of Sines given:**  
  Angle A = 30°, Angle B = 45°, side a = 10 cm  
*(e.g., see Application Exercises, Ex. 12.1)*

- **Key Formulas:**  
  Law of Sines: a/sin A = b/sin B = c/sin C  
  Triangle Angle Sum: A + B + C = 180°

- **Solution:**  
  First, find C: C = 180° – (30° + 45°) = 105°.  
  Then, b = (a·sin B)/sin A = [10·sin45°]/sin30° = [10·(√2/2)]/(½) = 10√2.  
  Similarly, c = (10·sin105°)/sin30° (you may leave c in exact form or approximate its value).

## **Chapter 13: Inverse Trigonometric Functions (CH13)**

**Question 7:**  
**If sin⁻¹(1/2) = θ, find cos θ.**  
*(e.g., see Inverse Function Exercises, Ex. 13.1)*

- **Solution:**  
  sin⁻¹(1/2) gives θ = 30° (in the principal range), hence cos θ = cos30° = √3/2.

## **Chapter 14: Solutions of Trigonometric Equations (CH14)**

**Question 8:**  
**Solve the equation:**  
  2cos²x – 3cos x + 1 = 0 for x in [0°, 360°].  
*(e.g., see Equation Solving, Ex. 14.2)*

- **Solution:**  
  Let y = cos x, so the equation becomes 2y² – 3y + 1 = 0.  
  Factorize: (2y – 1)(y – 1) = 0 → y = ½ or y = 1.  
  For cos x = 1, x = 0° (or 360°); for cos x = ½, x = 60° and x = 300°.  
  Thus, the solutions are x = 0°, 60°, and 300° (with 360° being equivalent to 0°).
